## 搬瓦工续费价格为什么和新购价格看起来不一样？

新购页面展示的是当前可购买方案，续费账单对应的是你账户里已经存在的服务。两者不是同一个概念。

举个简单例子：

- 你看到官网现在有 20G KVM，价格为 $49.99/年；
- 你的旧 VPS 可能是早期的其他配置；
- 这台旧 VPS 也许仍然可以续费，但它未必会在当前公共页面中单独展示；
- 客户端生成的续费账单，可能会继续按照原服务的账期和当前适用价格计算。

这也是为什么有些用户在官网看到一个低价方案，却发现自己账户里的续费金额不同。官网新购页面回答的是“现在购买这档产品多少钱”，而客户端账单回答的是“你现有这台服务器下一期需要支付多少钱”。

如果两者差异比较大，不建议直接取消旧服务再重新购买。这样做可能会导致：

- 原 IP 地址无法保留；
- 数据需要自行迁移；
- 原机房库存不足；
- 新方案无法选择相同地区；
- 退款政策不适用于续费订单；
- 旧服务到期后无法恢复原状态。

## 搬瓦工可以自动扣款吗？

根据搬瓦工官方知识库，搬瓦工不会自动从信用卡或 PayPal 中扣款，也不会保存用户的支付方式用于自动扣费。续费采用用户主动支付的方式。官方系统通常会在续费日前生成账单；如果账户中有足够余额，余额可以用于支付账单。

这意味着“开启续费”不等于银行账户会被自动扣款。

更准确地说：

- 续费状态开启后，系统会为下一期服务生成账单；
- 账户余额足够时，系统可能直接使用余额支付；
- 如果余额不足，系统会通知你补款；
- 你仍然需要确认账单并完成支付；
- 不建议等到到期当天才处理。

官方知识库说明，如果账户余额不足以覆盖账单，用户会收到通知，并有 7 天时间支付逾期账单；超过期限仍未付款，服务可能会被暂停。
